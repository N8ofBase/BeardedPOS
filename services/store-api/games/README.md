# Games for Beard Buddies

Web games served only to signed-in Beard Buddies at `/api/play/<slug>` (`src/handlers/play.ts`).
The site's page for each one is `/play/<slug>`.

- `mine-and-find.html` is a copy of `index.html` from the N8ofBase/MineAndFind repo (the public
  build at mineandfind.prismcortex.net). To update it, copy the new file over this one.
